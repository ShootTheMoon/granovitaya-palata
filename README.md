# 파세트궁 실내 — Грановитая палата

모스크바 크렘린 **파세트궁(Грановитая палата, 1487–91)** 의 **실내 복원** Blender 생성 스크립트입니다.
1953년 소련 실측도판 『Русское зодчество』 вып.2 Табл.12~15 를 픽셀로 재서 치수를 잡았습니다.

> **창작 모델이 아닙니다.** 같은 조직의
> [`kremlin-palace`](https://github.com/ShootTheMoon/kremlin-palace) 는 참고 이미지 기반의
> 창작 대크렘린궁이고, 이 레포는 **실측도판 기반의 파세트궁**입니다. 건물도 방법도 다릅니다.

## 왜 실내만인가

원래는 크렘린 앙상블 전체의 외피였습니다(성벽 2,235 m · 탑 20기 · 성당 4채 · 붉은광장).
그걸 전부 버리고 **방 하나만** 남겼고, 그 대가로 얻은 것이 **yaw 0 축정렬**입니다.

OVERDARE 익스포터(`shared/export_overdare.py`)의 `extract_boxes()` 는 월드 좌표에서
축정렬 박스를 찾습니다. 원래 발자국은 yaw 14° 라 바닥이 **네이티브 Part 가 될 수 없었습니다.**
원점에 축정렬로 세우니 그대로 통과합니다 — **Part 61개**, 걸어 다닐 수 있습니다.

## 구성

| | 치수 | 비고 |
|---|---|---|
| 대홀 | 22.4 × 22.4 m, 볼트 마루 9.0 | 중앙 기둥 1개(2.3 m 각)에서 네 모서리로 뻗는 교차볼트 |
| сени (현관홀) | 안목 5.1 m × 22.4 m | 원통볼트 + 횡단 리브 5개 |
| подклет (아랫층) | 30.0 × 22.4 m = 672 m², 유효 2.65 m | 기둥 격자 19개 + 평천장. 계단 18단으로 сени 와 연결 |
| 포털 | 1.45 × 2.75 | сени 격벽, 루넷 베이 중앙 |
| 창 | 8짝, 문턱 4.1 / 머리 7.26 | 반원 아치 + 안쪽으로 넓어지는 사면 여벽 + 사선 창살 |

좌표: 원점 = 블록 중심, yaw 0, z = 0 이 대홀 바닥.

## 사용

Blender 5.2 에서 `gyeongbokgung/` 과 `kremlin/` 이 `sys.path` 에 있어야 합니다.

```python
import kremlin.interior as interior
from kremlin import material

site, objs, info = interior.build(seg=14, collider=True, portal_bay=0, podklet=True)
material.apply(surfaces=material.SURFACES_INTERIOR)   # PolyHaven CC0 텍스처
interior.studio(site)                                 # 조명·카메라·월드
```

반출본은 `interior.build(seg=10)` 으로 볼트를 줄이고,
발행 직전에 `interior.set_collider_visible(ob, True)` 로 콜라이더를 켭니다 —
익스포터가 `hide_render` 가 켜진 오브젝트를 건너뛰기 때문입니다.

**폐쇄성 검증은 눈으로 하지 마세요.** EEVEE 가 월드광을 모든 면에 균일하게 먹여서
밝기로는 구멍인지 알 수 없습니다. 실내 여러 지점에서 피보나치 구로 `scene.ray_cast` 를
쏘고, 안 맞은 방향이 **창 사각형 안인지** 검사합니다. 현재 12지점 × 8,000방향에서
**창으로 설명 안 되는 누수 0** 입니다.

## Hunyuan3D 소품 — 아직 비어 있습니다

`docs/실내소품_생성지시.md` 에 소품 6개(옥좌 · поставец · 포털틀 2종 · 판카딜로 · сени 샹들리에)의
프롬프트와 Front View 입력이 준비돼 있지만 **생성은 아직 안 했습니다.**
받은 FBX 를 `kremlin/models_hunyuan/interior/` 에 규약대로 넣고 `interior_props.run()` 을 부르면
임포트·데시메이트·배치까지 갑니다.

도판을 세워 보고 확인한 것들:
- **поставец** 은 벽 선반이 아니라 **중앙 기둥을 사방에서 감싸는** 4면 구조물입니다
- 조명이 두 종류입니다 — 대홀은 **원환형 панникадило**, сени 는 **잎사귀 가지형 샹들리에**
- 포털도 두 종류입니다 — **오지형 첨두**(Табл.15)와 **끊어진 삼각 박공**(Табл.13)

⚠ 도판은 90° 돌아간 채로 인쇄돼 있습니다. **시계 90°**(`np.rot90(k=-1)`)가 맞습니다 —
반시계로 돌리면 글자가 거꾸로 섭니다. 판정은 캡션 글자로 하세요.

## 아직 도판과 다른 것

정직하게 적습니다. 지금 씬은 도판과 셋이 다릅니다.

1. **сени 볼트** — Табл.13 은 **교차볼트**를 보여 주는데 지금은 원통입니다.
   `vault.groin()` 의 칸 경계 누수를 못 잡아 우회한 것이고, 도판이 맞습니다
2. **바닥** — 실제는 홀 전체를 덮는 **큰 소용돌이 아라베스크**입니다. 지금 깐 석판은 임시입니다
3. **프레스코** — 벽·볼트가 전면 인물화입니다. 지금은 황토 단색 + 회벽 질감뿐입니다

2·3 은 3D 가 아니라 **타일링 텍스처**가 필요한 일입니다.
